# iOS 0.2 검증 상태

## 수행

- Python으로 Info.plist/PrivacyInfo.xcprivacy XML 파싱.
- Xcode 프로젝트 ID 중복과 8개 Swift 파일 포함 여부, shared scheme XML 확인.
- 빌드 셸 스크립트 bash 구문 검사.
- ZIP 압축 무결성 검사.

## 미수행 — 통과로 해석하면 안 됨

이 환경에는 Swift/iOS SDK/Xcode가 없습니다. Swift 타입 검사, 모델 테스트 실행, 시뮬레이터 빌드, 화면 렌더링, 실기기 알림·카메라·백업·복원, 서명·IPA·TestFlight 모두 미수행입니다.
`Tests/main.swift`와 `scripts/check-ios.sh`는 Mac에서 실행할 검사 코드입니다. 통과 기록이 아닙니다.

## Mac과 아이폰에서 확인할 항목

1. `bash scripts/check-ios.sh`: 모델 직렬화, 복제 ID/체크 독립성, 영양 계산, 입력 검사 후 iOS 시뮬레이터 빌드.
2. 첫 메뉴: 기본 iPhone/작은 iPhone/큰 글씨/타이머 동작 중 메뉴 접근. 기본 화면에는 웹 페이지나 브라우저 없음.
3. 운동: 새 종목 → kg/횟수 수정 → 뒤로가기/종료/재실행. 체크 시 휴식 하나만 시작. 취소 시 새 알림 없음. 반복 시 원본 체크 유지, 복사 체크 해제.
4. 식단: 저장한 음식 검색, 그람 계산, 최근 음식 선택, 제목 수정, 삭제 후 알림 취소.
5. 알림: 잠금/백그라운드/일시정지/재개/교체/종료/권한 거부/무음/음악 재생 상태.
6. 미디어: 사진·영상 가져오기·촬영·미리보기·재생·대표 지정·메모·개별 내보내기·삭제.
7. 전체 백업: iCloud Drive/내 iPhone으로 저장 후 앱 재실행 및 복원. 두 번 복원. 백업 원본 유지. 누락 파일/손상 JSON/경로 위조/큰 파일 거절. 저장 공간 부족 시 원래 기록 유지.
8. 백업 구성 파일의 날짜/용량 API 및 Privacy Manifest 필요 사유를 출시 전에 Apple 최신 요구에 맞게 점검.
9. 계정/커뮤니티/결제는 미연결 안내만 제공. 출시 전 실제 구현 필수.

큰 영상 가져오기와 복원 파일 쓰기에 동기 경로가 남아 있습니다. 실기기 성능·중단 시 복구 점검이 필요합니다. 계정 동기화/삭제 복구가 완료된 상용 앱으로 판매하면 안 됩니다.
